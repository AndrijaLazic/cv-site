# Project Guidelines

## Tech Stack

- **Framework**: TanStack Start (React 19, Vite 7, SSR)
- **Routing**: TanStack Router — file-based in `src/routes/`
- **Styling**: Tailwind CSS 4 + `tailwindcss-animate`, dark mode via `.dark` class + 3 theme variants via `data-theme` attribute
- **UI components**: Radix primitives in `src/shared/ui/` (shadcn/ui style with CVA + `cn()`)
- **Blog content**: MDX posts in `content/blog/{NNN-slug}/{locale}/` with `meta.ts` (eager) and `post.mdx` (lazy). Registry in `src/features/blog/registry.ts`.
- **i18n**: i18next + react-i18next, languages: `en`, `sr`. Locales in `src/features/i18n/locales/`
- **Testing**: Vitest + Testing Library (no test files exist yet)
- **Linting**: ESLint (`@tanstack/eslint-config`) + Prettier

## Commands

```bash
npm run dev        # Dev server on :3000 (--host 0.0.0.0)
npm run build      # Production build (Nitro outputs .output/)
npm run test       # Vitest run
npm run lint       # ESLint
npm run format     # Prettier check
npm run check      # Prettier write + ESLint fix
```

`npm run dev` binds to `0.0.0.0`; use `VITE_USE_POLLING=true` in containers/WSL.

## Architecture

```
src/
  routes/          # TanStack file-based routes (pages + API handlers)
  features/        # Feature modules: blog, i18n, theme, layout, preferences, devtools, resume
  shared/ui/       # Reusable UI primitives (badge, card, checkbox, etc.)
  shared/config/   # Public env config (VITE_SITE_URL, VITE_BACKEND_URL)
content/
  blog/            # MDX posts: /content/blog/{NNN-slug}/{en,sr,...}/
```

- Path aliases: `#/*` and `@/*` both map to `./src/*`
- `routeTree.gen.ts` is auto-generated by TanStack Router — never edit manually

## Conventions

- Use `cn()` from `src/shared/utils.ts` (clsx + tailwind-merge) for merging Tailwind classes
- UI components use CVA for variants
- No semicolons, single quotes, trailing commas (Prettier)
- TypeScript: `strict`, `noUnusedLocals`, `noUnusedParameters`, `verbatimModuleSyntax` — use `import type` for type-only imports
- Themes: `midnight-editor` | `graphite-neon` | `paper-terminal`, set via `<html data-theme>`, persisted in cookies. `graphite-neon` is the default.

## Blog Content Format

Each post lives at `content/blog/{NNN-slug}/{locale}/`:

- `meta.ts` — eager `PostMeta` export (slug, title, date, tags, etc.)
- `post.mdx` — lazy-loaded MDX content
- `postImages.tsx` — optional per-post image map

The registry (`src/features/blog/registry.ts`) builds an index from `import.meta.glob` at build time. A custom Vite plugin (`virtual:blog-post-sources`) feeds raw MDX source for ToC extraction.
